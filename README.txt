MY LOVE — ROMANTIC BIRTHDAY WEBSITE

HOW TO RUN
1. Extract the ZIP file.
2. Open index.html in a modern browser. For the best experience, use VS Code Live Server.
3. Replace assets/photos/photo-1.svg through photo-6.svg with your own pictures.
   If using JPG/PNG, update the matching image src paths in index.html.
4. To enable music, add your legally obtained audio as assets/audio/perfect.mp3.
   No copyrighted audio is included. The music player is disabled until a playable file is present.

CUSTOMIZATION
- Birthday date: edit the `birthday` value near the top of script.js.
- Display name and text: edit the text in index.html.
- Colors and layout: edit style.css.

TECH
HTML5 + CSS3 + Vanilla JavaScript. No framework or build step required.
